= MAS World 2026
:navtitle: Welcome

Welcome to *MAS World 2026*, a hands-on workshop exploring IBM Maximo Application Suite on Red Hat OpenShift.

== What You Will Learn

In this workshop, you will:

* Navigate Maximo Application Suite and understand its OpenShift foundation
* Use Red Hat Advanced Cluster Management to observe and govern a fleet of Maximo environments
* Apply updates to your Maximo environment
* Configure observability with OpenShift Logging and Loki
* Integrate an external identity provider with Keycloak
* Understand production architecture considerations

== Your Environment

You have a dedicated OpenShift {ocp_version} cluster with:

* IBM Maximo Application Suite {mas_version} (Core + Manage)
* OpenShift Logging with Loki
* Red Hat Advanced Cluster Management (fleet view)
* Keycloak for identity provider exercises
* This Showroom lab guide

== Workshop Structure

Each section follows this pattern:

. Automated validation to confirm success
. A solve path if you need help
