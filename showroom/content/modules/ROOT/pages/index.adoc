== What You Will Learn

In this workshop, you will:

* Navigate Maximo Application Suite and understand its OpenShift foundation
* Apply updates to your Maximo environment
* *Install and configure* the OpenShift Logging stack (Logging Operator, Loki Operator, Cluster Observability Operator)
* Integrate an external identity provider and sync LDAP users to Maximo
* Understand production architecture considerations

== Your Environment

You have a dedicated OpenShift {ocp_version} cluster with:

* IBM Maximo Application Suite {mas_version} (Core + Manage) -- *read-only, do not modify*
* Keycloak for identity provider exercises
* OpenLDAP with pre-configured users (alice, bob, carol, dave) for Maximo sync
* Pre-created S3 bucket for log storage
* This Showroom lab guide
