See how Red Hat Advanced Cluster Management (RHACM) manages a fleet of Maximo environments from a single management plane.

== Introduction

In production, organizations manage multiple Maximo environments across development, staging, and production. RHACM 2.16 provides:

* Fleet inventory and visibility
* Governance policies for compliance
* Search across all managed clusters
* Automated remediation

NOTE: This section is primarily a *presenter-led demonstration*. Follow along on the presenter's screen.

== Presenter Demonstration

The presenter will show:

. *Fleet Inventory* — all MAS World clusters registered with ACM
. *Cluster Labels* — event metadata applied to each cluster
. *Search* — querying across all managed clusters
. *Governance Policies* — the `policy-mas-world-baseline` compliance policy
. *Drift Detection* — one deliberately noncompliant facilitator cluster
. *Remediation* — enforcing the missing ConfigMap
. *Return to Compliance* — all clusters compliant

== Key Concepts

[cols="1,2"]
|===
| Concept | Description

| ManagedClusterSet
| Groups clusters by event or workload type

| Placement
| Selects clusters by labels for policy targeting

| ConfigurationPolicy
| Defines expected resource state on managed clusters

| Remediation
| `inform` (report only) or `enforce` (auto-fix)
|===

== Production Considerations

* In production, governance policies enforce security baselines across all MAS environments
* Policies can verify operator versions, logging configuration, identity provider setup
* ACM Search enables cross-cluster troubleshooting without logging into each cluster individually
