Congratulations on completing Maximo World 2026!

== What You Accomplished

In this workshop, you:

* [x] Verified access to your dedicated OpenShift cluster with MAS
* [x] Navigated the OpenShift Console, added projects to Favorites, and used the Search tool
* [x] Explored OpenShift and MAS update mechanisms and understood why version management matters
* [x] *Installed* the OpenShift Logging stack from scratch (Logging Operator, Loki Operator, Cluster Observability Operator)
* [x] Deployed a LokiStack with S3 backend and configured log forwarding
* [x] Verified persistent logging by deleting a Manage pod and querying its historical logs
* [x] Configured OpenShift group sync using the Group Sync Operator with LDAP
* [x] Understood production architecture considerations and troubleshooting techniques

== Key Takeaways

. *MAS on OpenShift* provides a consistent, scalable platform for enterprise asset management
. *OpenShift Logging + Loki* delivers scalable, queryable observability with S3 backend -- and you can install it yourself
. *Identity integration* connects MAS to your enterprise directory through the LDAP -> Keycloak -> OpenShift -> MAS chain
. *Automation* (Ansible, operators, GitOps) ensures repeatable, auditable deployments
